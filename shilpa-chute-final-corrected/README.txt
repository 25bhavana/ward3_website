SHILPA TULSHIRAM CHUTE — FINAL WEBSITE PACKAGE

FILES
- index.html: complete responsive website (HTML, CSS and JavaScript in one file)
- assets/images/shilpa-tulshiram-chute.jpg: supplied profile photograph

LANGUAGES
- Marathi is the default language. Use ENGLISH / मराठी in the header to switch.
- All visible bilingual content, form labels, placeholders, select options and page title are translated through data-mr/data-en attributes.

PHOTO GALLERY — HOW TO CHANGE PHOTOS
- Gallery images are currently remote illustrative images from Maharashtra-based public/community sources. They are not claimed to show Shilpa or her own activities.
- To replace one, open index.html and search for the relevant gallery card heading (for example “नागरिक भेटी”). Replace that card's <img src="..."> with the path to your own authorised image.
- Recommended: create assets/images/gallery/ and save photos there, e.g. assets/images/gallery/citizen-meetings-01.jpg. Then set that card's src to that relative path.
- Keep each image's alt text accurate. Use photographs you own or have permission to publish.
- You may add/remove gallery cards by copying/removing one <article class="gallery-card"> block in the gallery section.

SOCIAL / CONTACT LINKS
- Facebook, Instagram and WhatsApp are connected to the supplied links/phone number and use inline SVG icons. The globe icon returns visitors to the website home section.
- YouTube is not shown as a clickable social link because no channel URL was supplied. Add it only after providing the real channel URL.
- Phone and email use tel: and mailto: links.

QUOTE
- The quote now uses one semicolon in both Marathi and English.

TEST LOCALLY
1. Extract the ZIP. Keep index.html and the assets folder together.
2. Open index.html in Chrome.
3. Check Marathi default, switch to English, then back to Marathi.
4. Check all navigation, social links, WhatsApp, phone, gallery, and mobile layout.
5. Submit a test complaint only after FormSubmit activation.

GITHUB PAGES
1. Upload index.html and the complete assets folder to the repository root.
2. Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Wait for deployment and test the published URL.
